One perfect pickup line, a single line of at most 200 characters.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
Are you a compiler? Because every time I try to walk away, you find an error in my heart and refuse to let me run.
```
